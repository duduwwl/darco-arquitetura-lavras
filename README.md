# D’arco Arquitetura

Portfólio de arquitetura e interiores da D’arco Arquitetura, em Lavras, Minas Gerais.

**Site:** https://duduwwl.github.io/darco-arquitetura-lavras/

## Estrutura

Site estático publicado pelo GitHub Pages a partir da branch `main`, pasta `/ (root)`. A página principal contém seções de projetos, escritório, atuação e contato. As imagens e visualizações arquitetônicas estão em `assets/`.

## Créditos

Projetos e imagens: D’arco Arquitetura. Os links de publicação original no Instagram aparecem no próprio portfólio. Todos os direitos sobre as imagens pertencem a seus titulares.
